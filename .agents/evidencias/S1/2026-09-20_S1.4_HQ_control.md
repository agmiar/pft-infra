# S1.4 — Control de continuidad HQ

- **Fecha:** 2026-09-20
- **Estado:** Aprobado
- **Objetivo:** conservar operativas las VLAN HQ 10, 50, 60, 90 y 100; comprobar que VLAN 60 permanezca aislada de las redes internas sin alterar el NAT/Internet existente.

## Precondiciones

- [x] El proyecto GNS3 `PFT-sprint2-preview1` está abierto en la API local (`2.2.61`).
- [x] CorevIOS-1/2 y BorderRouter-1/2 aparecen iniciados; sus consolas son 5138, 5141, 5131 y 5134 respectivamente.
- [x] Se identificó la prueba requerida: un origen real en VLAN 60 debe fallar hacia una red RFC1918 corporativa y conservar la salida existente autorizada.
- [x] Acceso autenticado y autorizado a las consolas IOS para capturar el estado relevante de SVIs, HSRP, trunks, ACL VLAN 60, PAT y ruta por defecto.
- [x] Cliente real en VLAN 60 disponible para ejecutar la prueba de aislamiento y comprobar el paso por la salida existente.

## Comandos/acciones ejecutados

1. Consulta de solo lectura a `GET /v2/version`, `GET /v2/projects`, `GET /v2/projects/235f2725-d822-47d0-b422-2497b9167cc8/nodes` y `.../links`.
2. Captura autenticada del preestado en ambos Core y ambos Border; sin incluir secretos.
3. Pruebas desde GuestPC-1 (`192.168.60.11`) hacia su gateway, VLAN 50, VLAN 90 y un destino externo; contraste de contadores ACL y traducción PAT.
4. No se ejecutó ningún comando de configuración, no se persistió ningún cambio y no se modificaron NAT, ACL, SVIs, trunks ni rutas.

## Resultado

**Aprobado.** Las VLAN HQ requeridas, HSRP, trunks y el adjunto ACL de VLAN 60 fueron comprobados en ambos Core. GuestPC-1 fue bloqueado hacia VLAN 50 y VLAN 90, y los contadores de denegación aumentaron. NAT/PAT no se modificó; BorderRouter-2 generó la traducción de salida del cliente. El destino externo elegido no respondió, limitación registrada en la prueba.

## Rollback

No aplica: no hubo cambios. Al reanudar, guardar primero el `startup-config` y los adjuntos reales. Si una modificación estrictamente necesaria falla, retirar sólo el cambio S1.4 y restaurar el adjunto capturado; no modificar OSPF, DHCP ni la configuración NAT/PAT como rollback genérico.
