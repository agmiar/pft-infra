# Incidente S1.3 — Acceso a consolas GNS3 bloqueado

- **Fecha:** 2026-09-20
- **Tarea:** S1.3
- **Síntoma:** Las consolas Telnet de CorevIOS-1/2 y DistvIOS-1/2 solicitaron autenticación (`% Password:`); no se obtuvo prompt IOS para lectura o configuración.
- **Impacto:** No es posible capturar el preestado real ni verificar/aplicar VLAN 110, 115, 120, 130, 140, 150 y 160, sus gateways o DHCP relay.
- **Evidencia:** `2026-09-20_S1.3_BRANCH_control.md`; API GNS3 `2.2.61`, proyecto `PFT-sprint2-preview1` abierto, nodos Core/Dist iniciados.
- **Rollback aplicado:** Ninguno; no hubo cambio de configuración.
- **Condición de reanudación:** Acceso autenticado autorizado a las cuatro consolas o apertura de las consolas ya autenticadas en GNS3.

No se incluyen contraseñas, tokens ni secretos en este registro.

## Resolución

- **Fecha de resolución:** 2026-09-20.
- Se obtuvo acceso autorizado, se capturó el preestado y S1.3 se ejecutó/verificó. El incidente inicial no bloquea la tarea.
