# P3.1 — Revisión de ACL instanciadas

**Fecha:** 2026-09-20  
**Tarea:** P3.1  
**Estado:** Bloqueado  
**Artefacto:** revisión de ACL `PFT_*` contra la matriz de flujos.

## Objetivo

Instanciar y revisar las ACL `PFT_*` del runbook, sin marcadores, antes de cualquier adjunto a una SVI. La aceptación exige que las IP, interfaces, puertos y dependencias estén confirmados y que exista preestado/rollback verificable.

## Precondiciones

- Preestado real de CorevIOS-1 y CorevIOS-2: `show ip interface brief`, `show ip interface vlan`, adjuntos ACL y `startup-config`.
- Identificación del gateway HSRP activo y captura runtime de ambos Core.
- IP real de `WebUbuntuServer-1` y de los equipos de gestión.
- Matriz activa con protocolos/puertos concretos para DC1/DC2, FS-HQ, BKP-1, PVE y gestión.
- Definición de los protocolos/puertos de backup de BKP-1.

No se cumple la precondición de ACL `PFT_*` instanciadas ni existe captura runtime `show access-lists PFT_*` aportada para esta tarea.

## Comandos/acciones ejecutados

La revisión fue sólo documental y de consola local; no se aplicaron cambios de red, VMs, servicios ni configuraciones.

```text
rg -n -i '(^|[^A-Za-z0-9])PFT_[A-Za-z0-9_-]*' 'configs INFRA' .agents --glob '*.txt' --glob '*.md' --glob '*.csv'
rg -n '^(ip access-list|interface Vlan| ip access-group|access-list| ip address| standby)' 'configs INFRA/0. CorevIOS/CorevIOS-1.txt' 'configs INFRA/0. CorevIOS/CorevIOS-2.txt'
nl -ba .agents/ACL_MATRIZ_Y_RUNBOOK.md
nl -ba PLAN_DE_TRABAJO_UNIFICADO.md | sed -n '108,110p'
```

## Resultado verificado

1. **ACL `PFT_*`: no encontradas en las configuraciones activas.** Las coincidencias `PFT_*` están en documentación histórica o en referencias, no en una definición de ACL de `configs INFRA`.
2. **ACL actualmente descritas:** `VLAN_10_IN` a `VLAN_100_IN` y `FILTRO_DMZ`.
3. **CorevIOS-1:** el archivo contiene adjuntos `VLAN_*_IN` en las SVI 10, 20, 30, 40, 50, 60, 90 y 100 (líneas 45–94), y además muestra `FILTRO_DMZ` adjunta a `Vlan100` (líneas 253–264). Esto requiere validación runtime; el archivo no sustituye a `show running-config`.
4. **CorevIOS-2:** el archivo no muestra adjuntos `VLAN_*_IN` en las SVI; sólo muestra `FILTRO_DMZ` adjunta a `Vlan100` (líneas 116–127). La asimetría no se puede resolver por inferencia.
5. **La configuración textual contiene reglas históricas PVE/QNetd y pruebas temporales en `VLAN_50_IN`** (secuencias 75–78, líneas 339–345 de CorevIOS-1 y 204–209 de CorevIOS-2). No se afirma que estén activas en runtime sin una captura actual.
6. **La matriz/runbook activo** exige inventariar puertos, SVIs y preestado; prohíbe aplicar marcadores; y define sólo controles funcionales generales, no una lista completa de ACL `PFT_*` instanciable.
7. **La secuencia activa del plan** mantiene la segmentación pendiente hasta contar con BKP-1, sus protocolos/puertos autorizados y pruebas reales. Por tanto, no corresponde cargar una ACL incompleta para cerrar P3.1.

## Resultado

**Bloqueado.** P3.1 no puede aprobarse: no hay ACL `PFT_*` instanciadas sin marcadores ni matriz completa aplicable al diseño activo, y no existe evidencia runtime de sintaxis/adjuntos. No se creó ni adjuntó ninguna ACL.

## Rollback

No aplica rollback técnico porque no hubo cambios. Para una futura intervención, retirar sólo la ACL nueva de la SVI afectada y reponer exactamente el adjunto que se capture en el preestado; no modificar OSPF, DHCP, NAT ni interfaces como rollback genérico.
