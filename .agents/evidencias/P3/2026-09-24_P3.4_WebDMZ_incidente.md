# Incidente P3.4 — acceso de consola a Web DMZ

- **Fecha:** 2026-09-24
- **Tarea:** P3.4 — prueba Web DMZ.
- **Estado:** Bloqueado

## Síntoma

`WebUbuntuServer-1` fue iniciado junto con `ADvIOS-10` y alcanza su consola,
pero Ubuntu solicita un usuario y contraseña no incluidos en el inventario
operativo disponible. No se realizaron intentos de autenticación por adivinanza.

## Impacto

No se pudieron ejecutar desde Web DMZ las pruebas DNS hacia DC ni TCP/5432
hacia la VIP PostgreSQL. Esta limitación no demuestra por sí sola un fallo de
ACL; no obstante, CorevIOS-1 registró denegaciones reales de respuesta DNS
desde DC1 (`192.168.50.12:53`) hacia `192.168.100.6` y el postestado de
`PFT_V50_FUNC_IN` no contiene retornos UDP/53 para VLAN 100. La hipótesis queda
respaldada, pendiente de una prueba autenticada desde Web DMZ.

## Rollback y reanudación

No se aplicó cambio alguno. Para reanudar, el operador debe proporcionar o
usar una cuenta autorizada en Web DMZ, o habilitar un método de consola que no
requiera autenticación interactiva. Tras ello se ejecutarán las pruebas DNS y
TCP/5432 y se correlacionarán con los contadores ACL.
