# S2.1 — Procedimiento de rollback

- Tarea: S2.1.
- Fecha: 2026-09-20.
- Estado: Preparado; aplicado durante el incidente VNC únicamente en PVE-1 y luego se reintentó por SSH con éxito.
- No se incluyen credenciales.

## Respaldos

Antes de cada aplicación se ejecutó:

```text
cp -a /etc/network/interfaces /etc/network/interfaces.s2.1.pre
```

El archivo de respaldo quedó en cada PVE.

## Restauración de red PVE

```text
cp -a /etc/network/interfaces.s2.1.pre /etc/network/interfaces
ifreload -a
ip -br addr
ip route
bridge link
systemctl is-active pveproxy ssh
```

La restauración devuelve la IP antigua de `vmbr0`, retira `vmbr1` de la configuración y deja `ens4` manual.

## Restauración GNS3

Si fuera necesario retirar S2.1, reponer los enlaces previos de las segundas NIC:

- PVE-1 eth1 ↔ SwitchvIOSL3-1 adapter 1.
- PVE-2 eth1 ↔ SwitchvIOSL3-1 adapter 2.

Después se verifican los endpoints API, la conectividad por SSH/8006 y la configuración de los puertos IOS. No se ejecutó este rollback final porque la implementación SSH fue exitosa.
