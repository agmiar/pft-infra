## Limitaciones

- `qm agent 102 ping` y `qm agent 102 network-get-interfaces` devolvieron `QEMU guest agent is not running`.
- El estado `running` es estado de energía de QEMU; no acredita que Windows haya terminado de iniciar ni que tenga la IP de diseño.
- Rollback operativo preparado: `qm shutdown 101` y `qm shutdown 102` sólo si el operador solicita restituir el estado detenido. No se aplicó rollback.
