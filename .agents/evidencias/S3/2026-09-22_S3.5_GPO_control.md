# S3.5 — GPO de línea base, usuarios, actualizaciones, aviso y excepción TI

**Fecha:** 2026-09-22  
**Estado:** Bloqueado  
**Equipo ejecutor:** operador único del laboratorio  
**Alcance:** DC1-PFT y dominio `pft.test`.

## Objetivo y precondiciones

Se implementaron las GPO-01, GPO-03, GPO-05, GPO-06 y GPO-07 previstas para S3.5. La validación de aplicación en estaciones queda bloqueada hasta completar S3.7, porque las dos estaciones Windows aún no están unidas al dominio.

No se registran contraseñas, claves ni tickets.

## Cambios realizados

1. `GPO-01-Baseline`: política de bloqueo por inactividad mediante `InactivityTimeoutSecs=900`.
2. `GPO-03-Users`: marcador de perfil de usuario bajo `HKCU\Software\PFT\Users`.
3. `GPO-05-Updates`: Windows Update automático, `NoAutoUpdate=0` y `AUOptions=4`.
4. `GPO-06-LogonNotice`: título y texto de aviso legal de acceso autorizado.
5. `GPO-07-TI-Exception`: marcador de excepción bajo `HKCU\Software\PFT\Exceptions`, enlazado únicamente a la OU `TI`.
6. Las GPO-01, GPO-05 y GPO-06 quedaron enlazadas al dominio; GPO-03 a `OU=Usuarios-PFT`; GPO-07 a `OU=TI,OU=Usuarios-PFT`.
7. Se corrigió el filtrado de seguridad de GPO-07: `Authenticated Users` conserva lectura y `GG-TI` tiene aplicación.

## Evidencia real y aceptación

La salida de verificación de DC1 confirmó las cinco GPO con configuración habilitada, enlaces activos/no forzados y el filtrado de seguridad de GPO-07. No se declara aceptación completa porque aún faltan `gpresult` y la prueba de excepción en una estación real.

Ver [prueba S3.5](2026-09-22_S3.5_GPO_prueba.txt) y la configuración declarativa de [DC1](../../../configs%20INFRA/8.%20Windows-GNS3/DC1-PFT_S3.5.txt) y [DC2](../../../configs%20INFRA/8.%20Windows-GNS3/DC2-PFT_S3.5.txt).

## Cómo consultar

En un DC:

```powershell
Get-GPO -All | Sort-Object DisplayName | Select DisplayName,GpoStatus
Get-GPInheritance -Target 'DC=pft,DC=test'
Get-GPInheritance -Target 'OU=Usuarios-PFT,DC=pft,DC=test'
Get-GPInheritance -Target 'OU=TI,OU=Usuarios-PFT,DC=pft,DC=test'
```

En una estación unida al dominio:

```cmd
gpupdate /force
gpresult /h C:\Temp\gpresult.html
```

## Rollback

Desenlazar la GPO afectada y conservar el objeto para rollback; no borrar las GPO hasta finalizar la demostración. Para una prueba fallida en cliente, ejecutar `gpupdate /force` después de retirar el enlace y registrar el resultado.
