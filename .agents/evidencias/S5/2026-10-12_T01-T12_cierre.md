## Límites del cierre

- T09 queda aprobado para disponibilidad e inventario de ambos clientes.
- T10 queda aprobado también para ambos clientes: cada nodo fue detenido/iniciado mediante la API de GNS3, ZBX-1 observó el trigger `Windows: Zabbix agent is not available (for 3m)` y la recuperación quedó registrada con `agent.ping=1` y evento de valor `0`.
- La restauración formal acreditada es de archivo desde un respaldo real de FS-HQ, no una restauración completa de volumen/VM.
- S0.4 queda omitido y no es una compuerta de este cierre. Se conservan las exclusiones previas de S0.2, S0.3 y P3.1.
