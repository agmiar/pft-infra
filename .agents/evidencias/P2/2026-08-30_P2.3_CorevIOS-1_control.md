# Control de tarea P2.3 — DHCP CorevIOS-1

- **Fecha:** 2026-08-30
- **Tarea:** P2.3
- **Estado:** Aprobado

## Objetivo

En `CorevIOS-1`, excluir defensivamente `192.168.50.1` a `192.168.50.30` de DHCP y entregar DNS `192.168.50.12`, `192.168.50.13` y sufijo `pft.test` en los pools VLAN10, VLAN20, VLAN30, VLAN40, VLAN60 y VLAN90. No crear ni habilitar pool DHCP para VLAN50 o VLAN100.

## Precondiciones

- P2.2 está registrado como **Aprobado**: VLAN50 usa `/27`.
- P0.7 está registrado como **Aprobado**: existe control de aborto y rollback.
- Se obtuvo consola viva y se capturó estado previo/posterior aportado por el operador.

## Comandos / acciones ejecutados

- 2026-08-30: se revisaron las fuentes de verdad y el registro de evidencias.
- 2026-08-30: se comprobó que no hay una sesión de terminal adjunta ni procesos GNS3/vIOS disponibles desde este entorno; no se aplicó ninguna configuración desde este entorno.
- 2026-08-30: el operador aportó una sesión de CorevIOS-1 que muestra la exclusión `.1-.30`, DNS `.12/.13` y `domain-name pft.test` en los seis pools. `show ip dhcp binding` y `show ip dhcp conflict` están vacíos; Vlan50 y HSRP se mantienen estables.
- El operador ejecutó `do wr` con `[OK]`; `do show startup-config | section ^ip dhcp` confirma persistencia de la exclusión y de las opciones DHCP en los seis pools.

### Cambio autorizado para ejecutar tras disponer de consola

```cisco
conf t
ip dhcp excluded-address 192.168.50.1 192.168.50.30
ip dhcp pool VLAN10
 dns-server 192.168.50.12 192.168.50.13
 domain-name pft.test
ip dhcp pool VLAN20
 dns-server 192.168.50.12 192.168.50.13
 domain-name pft.test
ip dhcp pool VLAN30
 dns-server 192.168.50.12 192.168.50.13
 domain-name pft.test
ip dhcp pool VLAN40
 dns-server 192.168.50.12 192.168.50.13
 domain-name pft.test
ip dhcp pool VLAN60
 dns-server 192.168.50.12 192.168.50.13
 domain-name pft.test
ip dhcp pool VLAN90
 dns-server 192.168.50.12 192.168.50.13
 domain-name pft.test
end
```

No ejecutar `write memory` hasta completar y aprobar las verificaciones posteriores.

## Verificación posterior / aceptación

```cisco
show running-config | section ^ip dhcp
show ip dhcp binding
show ip dhcp conflict
show ip interface Vlan50
show standby brief
```

Se acepta sólo si la exclusión cubre `.1-.30`, los seis pools aplicables anuncian ambos DNS y `pft.test`, no existe pool para VLAN50/VLAN100, y no hay binding ni conflicto dentro del rango reservado. La renovación de clientes se difiere a P5.4, cuando existan DC/DNS `.12/.13`; no se declarará esa prueba como realizada ahora.

Aprobado: exclusión VLAN50 `.1-.30`, DNS `.12/.13` y sufijo `pft.test` configurados y persistidos; no hay bindings ni conflictos en la evidencia, ni pools DHCP para VLAN50/VLAN100. La renovación DHCP/DNS efectiva se difiere a P5.4 porque los DNS objetivo todavía no existen.

## Rollback

Antes de persistir, retirar exclusivamente la exclusión introducida y restaurar, desde la captura previa, las opciones `dns-server` y `domain-name` de cada pool que difiera. No tocar SVI, HSRP, OSPF, trunks, NAT ni pools ajenos a P2.3.
