## Rollback

No se aplicó rollback porque el operador pidió dejar el entorno listo. Para retirar sólo el acceso temporal:

```sh
# En PVE-1
ip addr del 172.31.255.2/24 dev ens4
ip link set ens4 down

# En LaptopUbuntu
sudo ip addr del 172.31.255.1/24 dev br-pft-transfer
sudo ip link set br-pft-transfer down
sudo ip link delete br-pft-transfer type bridge
```

DC1 y los nodos GNS3 se dejaron activos. Para revertir también el estado de encendido, apagar DC1 ordenadamente, detener los doce nodos arrancados en esta intervención y Cloud1, y cerrar el proyecto; conservar NAT1 según el estado que se confirme antes del rollback. No se tocó la configuración persistente de red de PVE ni se cambió AD/DNS/GPO.
