# Control de tarea P0.6 — Capacidad basal

- **Fecha de inicio:** 2026-08-30
- **Estado:** Aprobado

## Objetivo

Medir durante 10–15 minutos RAM disponible, swap, espacio libre de disco, CPU e I/O del host que ejecuta GNS3, bajo una carga declarada, y decidir si se puede continuar o si debe reducirse/redimensionarse la carga.

## Precondiciones

- Carga identificada: línea base de red con GNS3 activo; NAT1/DummyInternet, ISP/Border, Core, distribución/acceso y hosts ligeros visibles en la topología aportada por el operador.
- Sin PVE-1/PVE-2, QDevice, DC, PG ni Zabbix como carga integrada.
- No iniciar nodos adicionales ni modificar red, VMs, servicios o configuraciones durante la muestra.
- Conservar al menos 30 GB libres de disco; para validar la ventana crítica, sostener 2–3 GB de RAM disponible y no presentar crecimiento de swap atribuible a la carga.

## Comandos o acciones ejecutados

- Se revisaron las fuentes de verdad y se abrió este control documental.
- Se ejecutaron 12 muestras no intrusivas entre 05:05:46 y 05:15:52 UTC-03:00 (10 min 06 s), usando `/proc/meminfo`, `df -B1`, `vmstat 1 2` e `iostat -d -k 1 2`.

## Resultado

Aprobado para la línea base de red: se reservaron los márgenes de RAM y disco, no hubo paginación ni espera de I/O atribuibles a la carga y no se observó saturación sostenida. No acredita RQ-09, pendiente de P7.4 con carga integrada.

## Rollback

No aplica: P0.6 es observación no intrusiva. Si aparece swap sostenido, disco insuficiente o saturación atribuible a recursos, detener la carga de prueba y registrar la condición antes de continuar.
