# Control P1.3 — Inventario de Web DMZ

- **Fecha de inicio:** 2026-08-30
- **Tarea:** P1.3
- **Estado:** Bloqueado
- **Equipo objetivo:** `WebUbuntuServer-1` (frontend único previsto en DMZ/VLAN 100)

## Objetivo

Confirmar por consola del frontend su IP estática, prefijo, ruta por defecto, DNS efectivo y pertenencia a VLAN 100. El resultado real sustituirá el marcador `<IP_WEB_DMZ>` en tareas posteriores; esta plantilla no lo sustituye ni acredita un cambio técnico.

## Precondiciones

- P1.1 y P1.2 figuran aprobadas como inventario previo.
- Las SVI de VLAN 100 registradas en P1.1 están `up/up`: CorevIOS-1 `192.168.100.2/29`, CorevIOS-2 `192.168.100.3/29` y HSRP `192.168.100.1`.
- La P1.2 identifica al frontend actual como `WebUbuntuServer-2`, previsto para renombrarse a `WebUbuntuServer-1`, con referencia documental `192.168.100.6/29`. Esa referencia no es una confirmación de consola y no se usará como IP real hasta verificarla.
- Se requiere acceso de consola autorizado al frontend actual. No se modificará IP, gateway, DNS, nombre, VLAN ni ACL durante esta tarea.

## Comandos o acciones ejecutados

Ejecutados y aportados por el operador desde la consola del frontend:

```bash
hostnamectl
ip -br address
ip route
resolvectl status || cat /etc/resolv.conf
ip -d link show
```

En ADvIOS-10 se verificaron `show interfaces status`, `show interfaces switchport` y `show mac address-table interface Gi1/1`. Gi1/1 es el puerto conectado al frontend y opera como access VLAN 100. No se registraron secretos.

## Archivos de evidencia

- `2026-08-30_P1.3_WebUbuntuServer-1_inventario.txt` — salida saneada de los comandos del frontend y validación de VLAN 100 del switch.
- `2026-08-30_P1.3_WebUbuntuServer-1_control.md` — esta plantilla de control.

## Criterio de aceptación

La evidencia debe demostrar una única IP estática utilizable de `192.168.100.0/29` en el frontend, gateway por defecto `192.168.100.1`, DNS configurado sin inventar los servidores aún no desplegados, y puerto/segmento L2 correspondiente a VLAN 100. Si DNS todavía no es `.12/.13`, se registra el valor real como estado previo: no se cambia en P1.3.

## Resultado

Bloqueado. El frontend actual `WebUbuntuServer-2`/`ubuntu-server` tiene `ens3` activa con `192.168.100.6/29`, gateway estático `192.168.100.1` y MAC `0cf8.f860.0000`. ADvIOS-10 confirma esa MAC en `Gi1/1`, access VLAN 100. No hay servidor DNS configurado según `resolvectl status`, por lo que no se cumple la comprobación completa de P1.3.

## Rollback

No aplica: P1.3 es exclusivamente de inventario y no autoriza cambios. Si durante la comprobación se detecta una configuración inesperada, detener la tarea y preservar las salidas; no corregirla dentro de P1.3.
