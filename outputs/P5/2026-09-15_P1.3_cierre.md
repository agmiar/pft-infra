# Addendum P1.3 — resultado de la dependencia DNS de P5.1

**Fecha:** 2026-09-15  
**Estado:** la condición DNS que mantenía bloqueado P1.3 quedó satisfecha; se conserva la evidencia y la limitación de que la configuración de switch no se recapturó en esta sesión.

El frontend activo WebUbuntuServer-1 (ubuntu-server) fue identificado desde el propio invitado: ens3 UP, 192.168.100.6/29, gateway estático 192.168.100.1, MAC 0c:f8:f8:60:00:00. La MAC/IP coinciden con la evidencia histórica P1.3. La topología GNS3 mantiene el enlace del frontend a ADvIOS-10; no se modificó configuración de switch ni ACL. La evidencia P1.3 original ya registró el puerto access VLAN 100; no se ejecutó un nuevo show interfaces switchport durante este cierre.

Como resultado de P5.1, Netplan de ens3 tiene DNS 192.168.50.12 y 192.168.50.13. resolvectl status confirma ambos servidores en ens3 y resolvectl query web.pft.test resuelve efectivamente 192.168.100.6. Antes del cambio el frontend no tenía DNS efectivo y ambos DNS devolvían NXDOMAIN para web.pft.test; esas capturas se enlazan en el índice de P5.

Esto acredita la condición DNS exigida por el control P1.3 y permite considerar resuelto el bloqueo funcional con evidencia compuesta: inventario IP/ruta/MAC actual, validación de VLAN 100 histórica y resolución efectiva posterior. No se afirma que se haya validado HTTP/HTTPS, servicio web ni forwarding DNS externo; no forman parte del criterio P1.3 leído.

La plantilla de control y el índice originales bajo Downloads\pft-infra-main\.agents no se modificaron porque son de solo lectura en este entorno. Este addendum se guarda únicamente en la carpeta autorizada outputs\P5.
