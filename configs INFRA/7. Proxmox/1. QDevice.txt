# Descargar Debian 12 oficial
En el host Ubuntu, abrir una terminal
cd ~/Downloads
curl -fLO https://cdimage.debian.org/cdimage/archive/12.12.0/amd64/iso-cd/debian-12.12.0-amd64-netinst.iso
curl -fLO https://cdimage.debian.org/cdimage/archive/12.12.0/amd64/iso-cd/SHA512SUMS
grep 'debian-12.12.0-amd64-netinst.iso$' SHA512SUMS > debian-12.12.0-amd64-netinst.iso.sha512
sha512sum -c debian-12.12.0-amd64-netinst.iso.sha512

--------

En GNS3:
1. Edit → Preferences → QEMU VMs → New.
2. Crear una VM QEMU vacía con estos valores:
   - Nombre: PVE-QDEVICE
   - RAM: 512 MB
   - vCPU: 1
   - Disco: nuevo, qcow2, 8 GB
   - Adaptadores: 1
   - Tipo de adaptador: e1000
   - Consola: VNC
3. En las propiedades de la VM, monta debian-12.12.0-amd64-netinst.iso como CD/DVD.


--------

Arrancar PVE-QDEVICE y elegir
- Install
- Nombre de host: pve-qdevice
- Dominio: pft.test
- Red: usa DHCP sólo durante la instalación.
- Particionado: Guided - use entire disk.
- Selección de software: desmarcar entorno de escritorio; dejar sólo SSH server y standard system utilities.
- Instala GRUB en el disco principal y reinicia.
- Retirar la ISO al reiniciar.

useradd --system --home /var/lib/etcd --shell /usr/sbin/nologin etcd
install -d -o etcd -g etcd -m 0750 /var/lib/etcd

nano /etc/systemd/system/etcd.service
----------


[Unit]
Description=etcd key-value store
After=network-online.target
Wants=network-online.target

[Service]
Type=notify
User=etcd
Group=etcd
ExecStart=/usr/local/bin/etcd \
  --name etcd-qd \
  --data-dir /var/lib/etcd \
  --listen-peer-urls http://192.168.90.28:2380 \
  --initial-advertise-peer-urls http://192.168.90.28:2380 \
  --listen-client-urls http://192.168.90.28:2379,http://127.0.0.1:2379 \
  --advertise-client-urls http://192.168.90.28:2379 \
  --initial-cluster etcd-pg1=http://192.168.50.14:2380,etcd-pg2=http://192.168.50.15:2380,etcd-qd=http://192.168.90.28:2380 \
  --initial-cluster-state new \
  --initial-cluster-token pft-etcd-1
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
